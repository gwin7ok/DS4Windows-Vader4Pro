# フェーズ2 実機回帰テスト仕様書・チェックリスト (完全網羅版)

## 1. 概要
- **対象範囲**: Step 2-4（Actions/マクロ14箇所置換）および Step 2-5（通常1:1マッピング48箇所置換）
- **目的**: 仮想キーボード・マウス（KBM）出力が `IVirtualKBM` に統一されたことによる機能欠落（Feature Drop）がないかを実機で完全に担保する。
