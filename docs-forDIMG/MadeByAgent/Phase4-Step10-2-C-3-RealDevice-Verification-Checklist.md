## 本リストの位置づけ

本リストは、Step10-2-C-3 の専用プロファイル適用サービス、`ProfileSwitchAction.Stop()` を入口とする復帰処理、および Action 連鎖処理を実機で確認するためのチェックリストである。

確認後は、結果（`○`: 正常動作、`△`: 一部制限あり、`×`: 不具合あり、`未実施`）およびメモを記入すること。特に、一時プロファイル適用時の `isTemp=True`、通常プロファイル復帰時のロード回数、`UntriggerAction` の消費状態をログで確認する。

### 特に確認する状態

- 通常プロファイル名: `ProfilePath`、`OlderProfilePath`、`SelectedProfile`
- 一時プロファイル名: `tempprofilename`
- 一時状態: `useTempProfile`
- 保留解除Action: `UntriggerAction`
- 復帰対象名: `prevProfileName`
- 復帰対象の一時状態: `prevProfileWasTemporary`

### 復帰分岐の確認

- 復帰対象のプロファイル名が空の場合でも、既存仕様どおり通常プロファイルロードへ進むこと。
- 復帰対象の名前があり、`prevProfileWasTemporary=true` の場合は一時プロファイル処理へ進むこと。
- 通常プロファイル復帰では `ProfilePath` を設定してから `LoadProfile` を1回だけ実行すること。
- `ProfileSwitchAction.Stop()` が復帰の入口となり、Mappingが直接 `LoadProfile` または `LoadTempProfile` を実行しないこと。

### ログ確認

- 一時プロファイル適用時に `ApplyProfile ... isTemp=True` が出力される。
- 復帰時に `ProfileSwitchAction.Stop()` から `RestoreProfile` が呼ばれる。
- 復帰時に元プロファイルAの `LoadProfile` が1回だけ実行される。
- 復帰時の `LogProfileChanged` が元プロファイルAを示す。
- `SpecialAction UNTRIGGER check` が解除後も継続的に反復しない。

## 7. 総合判定

C-3-6 の完了条件は、プロファイルが切り替わることだけではなく、次のすべてを含めて既存動作が維持されることである。

- [△] 通常プロファイル切替が1回の操作で1回だけ実行される。
- [○] 一時プロファイル適用時に `isTemp=True` となる。
- [○] 復帰時に元プロファイルが正しくロードされる。
- [○] 復帰処理が `ProfileSwitchAction.Stop()` を入口として1回だけ実行される。
- [○] 復帰後に一時プロファイルの設定が残らない。
- [○] 入力停止・再開が正常で、押下状態が残らない。
- [○] 通知とログが重複しない。
- [？] Action連鎖が二重実行・無限再帰しない。
- [○] 接続・切断・再接続・終了時に例外やフリーズがない。
