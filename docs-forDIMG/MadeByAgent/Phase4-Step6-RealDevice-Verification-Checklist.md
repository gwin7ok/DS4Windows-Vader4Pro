## 本リストの位置づけ

本リストは、Phase4 の **全バックエンドサービス（第1層〜第3層 ＋ 第4層 4-c 設定／状態サービス群）の DI 化** および **`AppHost` による Composition Root 一本化（Step 6）** が完了したマイルストーンにおいて、**実機コントローラー・仮想コントローラー出力（ViGEmBus）・WPF UI・OS連携機能** を用いた結合動作確認を行うためのチェックリストである。

自動テスト（`DS4Windows.Actions.Tests` 71件、`StandaloneTests` 13件、`CompositionRootTests`）で担保済みの DI コンテナ解決・単体ロジックと切り分け、**実機環境および Windows OS 連携でしか確認できない項目** を対象とする。

各項目は、確認後に結果（`○`: 正常動作、`△`: 一部制限あり、`×`: 不具合あり、`未実施`）およびメモを記入すること。
