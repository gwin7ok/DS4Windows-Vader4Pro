## 本リストの位置づけ

本リストは、Phase4 の中核データ基盤（Step1: `IProfileSettingsService`、Step2: `IProfileRepository`、Step3: `ISpecialActionRepository`）の DI 化が一巡した段階において、**実機コントローラー・実際の WPF UI 操作・物理 XML ファイル（`Profiles/*.xml`, `Actions.xml`）を用いたエンドツーエンドの動作確認** を行うためのチェックリストである。

自動テスト（`DS4Windows.Actions.Tests` 31件、`StandaloneTests` 13件、および各新設単体テスト）で担保済みの範囲（型変換、配列境界、同期ロジック等）と切り分け、**実機環境でしか確認できない項目** を対象とする。

各項目は、確認後に結果（`○`: 正常動作、`△`: 一部制限あり、`×`: 不具合あり、`未実施`）およびメモを記入すること。
