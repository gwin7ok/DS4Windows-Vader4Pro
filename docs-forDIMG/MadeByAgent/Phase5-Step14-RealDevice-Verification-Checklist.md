## 本リストの位置づけ

本リストは、Phase5 全体（特に Step2〜Step13）の DI 化完了後に、**既存機能が維持されていること**と、**6大アーキテクチャ・ガードレールが実機でも機能していること**を確認するための総合実機検証チェックリストである。

- 自動テストで担保できる範囲（Actions / Standalone / 新規単体テスト）は別途「自動テスト結果」として記録する。
- 本リストには、**実機コントローラ・ドライバ・UI操作・長時間動作がなければ検証できない項目**を中心に記載する。
- 確認後は、結果（`○`: 正常動作、`△`: 一部制限あり、`×`: 不具合あり、`未実施`）およびメモを記入すること。
- 特に、`[DI]` ログ経路、`HaltReportingRunAction`、一時プロファイル復帰、AutoProfile、ViGEm スロット着脱、UI からの静的参照排除後の挙動を重点確認する。

## 12. 総合判定

Phase5-Step14 の完了条件は、単に「動く」ことではなく、次をすべて満たすことである。

- [ ] 自動テスト（Actions / Standalone / 新規）がすべて成功する
- [ ] ビルドが成功し、起動・主要 UI に致命的回帰がない
- [ ] プロファイル読込・保存・適用・復帰が正常
- [ ] 一時プロファイルの残留・復帰不具合がない
- [ ] Halt による入力停止／再開が正常で、押下残留がない
- [ ] AutoProfile が競合なく動作する
- [ ] SpecialAction / マクロ / 連鎖が二重実行や無限再帰しない
- [ ] 接続・切断・再接続・終了時に例外やフリーズがない
- [ ] 出力スロット（ViGEm）着脱・終了時に異常がない
- [ ] Step13 後の UI 操作で機能欠落がない
- [ ] 6大ガードレール起因の実機不具合が新規に出ていない
